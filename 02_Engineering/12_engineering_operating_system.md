- Rule 1 — Think Before Build .
No development begins before the problem is understood.

- Rule 2 — Design Before Code.
 No development begins before the design review.

- Rule 3 — Documentation Is Deliverable.
Documentation is part of the product, not an additional task.

- Rule 4 — Every Decision Has a Reason.
Every engineering decision must have a documented rationale.

- Rule 5 — Simplicity Wins.
If two solutions achieve the same goal, we choose the simpler one.

- Rule 6 — Continuous Improvement.
There is no perfect system. There is a system that is constantly improving.
